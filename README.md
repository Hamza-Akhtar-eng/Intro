# Projects

## EEG-Based Epilepsy Detection System

**Description:**  
A research-driven diagnostic web application built using .NET and React. It automates epilepsy detection from EEG signals using deep learning models (CNN, RNN). Designed to support clinicians by providing fast, reliable assessments, especially in resource-limited environments.  

**Technologies Used:**  
ASP.NET Core, React.js, Python (TensorFlow, Keras), PostgreSQL  

**Key Features:**  
- EEG signal preprocessing and feature extraction  
- ML model selection (CNN, RNN, SVM)  
- Waveform visualization and 3D scalp mapping  
- Diagnostic report generation and treatment recommendations  
- Role-based authentication and secure data management
